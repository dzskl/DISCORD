🔧 Como arrumar

Se o "Crie a conta de owner" aparece pra todo mundo, é porque o banco de dados está sendo apagado a cada deploy. Os usuários cadastrados somem.

Se o login não persiste, as sessões também estão sendo apagadas a cada reboot.

Se o login com Discord não funciona, as credenciais OAuth não estão configuradas (ou foram apagadas junto com o DB).

No Railway:
  1. Settings → Volumes → Add Volume — monte em /app/data
  2. Variables → New Variable:
    • SESSION_SECRET = gerar com openssl rand -hex 32
    • PUBLIC_URL = https://seu-app.up.railway.app
    • NODE_ENV = production
  3. Redeploy — agora o DB persiste entre deploys
  4. Acesse /setup.html e cole DISCORD_CLIENT_ID e DISCORD_CLIENT_SECRET do Discord Developer Portal
  5. No Discord Developer Portal → OAuth2 → Redirects, adicione: https://seu-app.up.railway.app/auth/discord/callback
